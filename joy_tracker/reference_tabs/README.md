la capture réelle fournie par l'utilisateur. L'OCR local ne lit pas ce libellé.

`dollar_menu.png` les deux signes dans la liste latérale.
Ces images servent uniquement à nommer l'onglet sélectionné `$$` ; la géométrie
et l'inventaire Currencies restent séparés de ceux d'Expédition.
